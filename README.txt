READY-TO-USE ACCOUNTING WEB APP

STEP 1
Install Python: https://python.org

STEP 2
Install libraries

pip install -r requirements.txt

STEP 3
Run the app

streamlit run app.py

STEP 4
Browser akan otomatis terbuka di:
http://localhost:8501

Fitur:
- Dashboard
- Chart of Accounts
- Journal Entry
- Ledger
- Trial Balance
- Income Statement
- Balance Sheet
